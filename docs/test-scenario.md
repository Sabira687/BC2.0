# Сценарий сквозного тестирования AIGO Collection

Проверяем продукт так, как его увидит жюри: открывает ссылку, проходит основной путь за несколько минут, пробует свои данные и читает репозиторий. Сценарий запускаем дважды: на локальной production-сборке (`cd web && npm run build && npm start`) до 09:00 и на живой ссылке после деплоя.

## Подготовка

- Чистый профиль браузера (инкогнито), чтобы localStorage был пуст.
- Два размера: компьютер 1440 px и телефон 375 px.
- Открыта консоль разработчика: в ней не должно быть ошибок, а CSP ничего не блокирует.
- На сервере задан `ANTHROPIC_API_KEY`. Живые вызовы Claude — только в шаге A5 (один урок) и A6 (одна помощь).
- Таймер: основной путь A должен укладываться в 5 минут.

**Статусы:** ✅ прошло · ⚠️ работает, но есть замечание · ❌ ошибка. Каждая ошибка заносится в журнал в конце с уровнем: **Блокер** (жюри не пройдёт путь), **Серьёзно** (заметно и портит впечатление), **Мелочь**.

## A. Основной путь — «жюри за 3 минуты»

| № | Шаг | Что делаем | Ожидаемый результат |
|---|---|---|---|
| A1 | Лендинг | Открыть `/`. Провести курсором по hero. Навести на 5 предметов в хранилище. Пролистать до конца | Страница открывается быстрее 3 с. Видны глитч-заголовок, след из звёзд за курсором, полоса «QUICK DEMO · 3 MIN». При наведении панель показывает историю предмета. Путь переключает точки. Билеты Free и Premium на месте, Roadmap «Big plan. Real parts.» тоже. Нигде нет слов jury, judges, hackathon |

Заблокированные поля не меняются, экранный диктор называет их заблокированными |

| A4 | Коллекция | «MAKE MY ITEMS ▸» → `/collection` | Счётчик «x / 45» хорошо виден. Set 01 открыт: Key, Lock, Compass (или «Create» с анимацией раскрытия — работают Skip и Esc). Наборы 02–07 подписаны «Free · after the demo», 08–15 — Premium ★. Карты приподнимаются при наведении |

| A7 | Урок в консоли | «OPEN IN CONSOLE» → вставить предмет (или он уже активен). «Use this answer» → SEND | Предмет показан карточкой с иллюстрацией, первая строка Claude — `▶ ITEM ACTIVATED · LEARN · Three-Tooth Key`, обращение к Anna. Ответ идёт потоком и начинается в пределах ~10 с. Видны рамки `━━━`, `┌─ YOUR TURN`, полоса `████░░░`. После проверки — рамка `CHECK` с `[✓]`, `✅ CHECK PASSED · ★☆☆` и `✦ STAMP EARNED · Brief formula`. Звезда на мини-карте и марка появились сами, без кода |

| A9 | Work chat | Вкладка WORK CHAT → «LOAD SAMPLE CHAT» → «USE COMPASS» | Пример помечен «SAMPLE CHAT · DEMO DATA». Компас показан карточкой, Claude отвечает `▶ ITEM ACTIVATED · HELP · Pocket Compass`, рамками ONE BETTER MOVE и TRY THIS и строкой `HELP USED`. Справа «Counted automatically · Help used» |
| A10 | Прогресс | `/progress` | В небе навыков горят звёзды по реальному прогрессу (1.1, Help), следующая отмечена «NEXT». В паспорте марок есть Player One и Brief formula. «What you can do now» заполнен |
| A11 | Перемотка | «FAST-FORWARD JOHN» | Созвездие-ключ горит целиком 7/7. Марок 4/13. Есть значок набора и голограмма. Плашка честно помечена «DEMO ONLY» |
| A12 | Результат | «See John's test result» (или «Read code») | «READING CODE_», затем голографический Proving Lock, 90/100, звёзды загораются по одной. Задания ✓/✗ (q3 ✗), «One thing to practice → Lesson 1.3» |
| A13 | Повторный и мусорный код | На Progress вставить тот же код, затем `hello` | «Already counted»; понятная ошибка про формат, без падения |
| A14 | Back to now | «BACK TO NOW» | Прогресс вернулся к состоянию до перемотки (1 звезда, 2 марки) |
| A15 | Premium | `/pro` → «GET PREMIUM» | Три билета с «WHY IT'S REAL». Тестовая оплата → «✓ PREMIUM ACTIVE · TEST MODE». Set 02 в коллекции остаётся закрытым |
| A16 | Guide | `/guide` | 6 шагов с мини-визуалами, «Two ways to learn», карточка коннектора. Ссылки ведут в коллекцию и консоль |

**Итог пути A:** всё ✅, путь занимает не больше 5 минут, в консоли браузера нет ошибок.
