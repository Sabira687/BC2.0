## 01. Задача (The Challenge)

**Построить веб-продукт, который закрывает фундаментальную боль взрослых людей в США — такую, за решение которой они готовы платить.**

| Параметр | Требование | Пояснение |
|---|---|---|
| **Аудитория** | США, 25–45 лет | Работающие взрослые: работа, семьи, счета, цели |
| **Модель** | B2C | Продаём людям, а не компаниям |
| **Платформа** | Только веб | Работает в браузере. Никаких мобильных приложений |
| **Время** | 24 часа | От идеи до работающего продукта |

## 02. Треки (Tracks)

**Выбрать ОДИН трек.** Три территории боли:

| # | Трек | Описание | Ключевой вопрос |
|---|---|---|---|
| 01 | **Money (Деньги)** | Заработок, траты, сбережения, долги | Где деньги причиняют боль? |

## Уточнения из FAQ организаторов

### Продукт и «только веб»
- Нужен **деплой**: живой продукт по публичной ссылке. Локальный сервер, Figma или **видео-демо не засчитываются** (Q1). Видео-демо не нужно вообще (Q145).
- «Только веб» = продукт работает **в браузере**, на десктопе или телефоне (Q2, Q60). Жюри должно открыть продукт по ссылке **и пользоваться им без установки чего-либо**; расширение — только как дополнение, если основной сценарий работает на сайте (Q40). PWA — можно (Q40, Q87).
- Оценивается веб-продукт: ключевая ценность должна быть **в нём** и работать end-to-end по ссылке (Q44).
- Жюри открывает продукт, **пробует свои данные и читает код** (Q96, Q134). Смотрят 15 ноября с 12:00 до 15:00, в браузере; адаптив под мобильный — плюс (Q70).
- Работать должен только **ключевой сценарий**, по-настоящему, без заглушек; лишние кнопки лучше убрать (Q3, Q85).
- Демо-режим, тестовые и seed-данные — можно, если проходят через настоящую логику и помечены как демо (Q35, Q66, Q69, Q84, Q94). localStorage и анонимные сессии — можно (Q135).
- Ссылка должна работать минимум до конца финала 15 ноября (Q47, Q73).

### ИИ
- LLM и платные API разрешены; ядро на LLM считается настоящим, если **работает вживую на вводе пользователя** (Q36, Q56, Q90). Ключи — только на сервере, не в репозитории; API должно быть доступно во время проверки (Q26, Q48). Расходы — на команде (Q131).
- Продукт должен быть **больше, чем обёртка**: структурированный путь к результату, накопленные данные и прогресс, персонализация, игровые механики (Q32, Q56, Q136).

### Деньги и удержание
- **Пейвол с понятной ценой — минимум**; Stripe в тестовом режиме — плюс; одной страницы с ценами без пейвола мало (Q37, Q55, Q67, Q137). Подписка не обязательна (Q51).
- В продукте должна быть **хотя бы одна работающая механика возврата** (прогресс, план, напоминания) (Q72, Q100).
- Жюри ценит **продление подписки**, а не ежедневную активность (Q30).
- В деке — цифры: цена, CAC по каналам, удержание, LTV, с источниками (бенчмарки RevenueCat, Adapty) (Q33, Q58, Q81, Q142).

### Новизна
- Не копировать продукты организатора: **Coursiv учит ИИ-инструментам для работы**, Finelo — финансам (Q12, Q57). Ниша не минус, минус — повторить продукт; нужен новый угол: аудитория, механика или ценность (Q31, Q41, Q97).

### Дек и питч
- Дек на английском, PDF, **до 10 слайдов всего**, включая титульный (Q53, Q75, Q81). Видео в PDF не работает — показывать продукт скриншотами (Q76, Q121).
- Интерфейс продукта — на английском (Q75). Питч и ответы — на казахском, русском или английском (Q109).
- Репозиторий — публичный, с полным кодом того, что задеплоено, без секретов; README с запуском — плюс (Q23, Q46).
