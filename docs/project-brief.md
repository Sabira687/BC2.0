## 2. Аудитория

Подробно: [audience-analysis.md](audience-analysis.md), [age-psychology.md](age-psychology.md), [target-audience.md](target-audience.md).

**Целевой пользователь:** американцы **28–33 лет**, открытые к новому и к технологиям, которые активно ищут смысл и возможности, чувствуют, как уходит время, хотят поскорее устояться и недовольны нынешними обстоятельствами.

**Отсекаем:** старше 35 (труднее продать новое), ярых консерваторов, традиционалистов, луддитов, устоявшихся.

**Общая картина (возраст × эпоха):**
1. **Кризис тридцатилетия** — «прожито три десятилетия, а куда я шёл?». Давят общество, время и собственное эго.
2. **Крах Американской мечты** — то, что должно было помочь, ухудшило положение: технологии → угроза работе, диплом → долги, государство → разочарование. Только 22% людей 18–29 лет верят, что мечта ещё существует.
3. **Поток стремительных изменений** — в возрасте, когда хочется стабильности, всё меняется каждый день.

**Размер сегмента:** ~6 млн человек (грубая оценка на допущениях).

## 3. Трек

**03 — Skills (Навыки).** Развлечения отсечены (рынок перенасыщен, не закрывает боли). Деньги отклонены (продукт про оборону и контроль, а не про перемены; рынок забит).

**Опора:** желание перемен — проломить ситуацию, достичь успеха и смысла, снова ощутить искру молодости. **Чувство, что не всё потеряно.**

Исследование трека: [skills-research.md](skills-research.md). Ключевое: учиться ИИ хотят 76%, онлайн-курсы заканчивают 2–6.5%, даже Duolingo через 90 дней удерживает 9%. Разрыв на каждом шаге: что учить → где взять время → как не бросить → как превратить навык в перемены.

## 4. Идея продукта

**ИИ-ассистент сам учит человека пользоваться собой.** Пользователь проходит анкету на нашем сайте и получает цифровые предметы — блоки инструкций в ностальгическом игровом стиле. Вставленный в чат предмет переключает ИИ в режим наставника по самому себе.

Механика: [product-mechanics.md](product-mechanics.md). Шаблоны предметов: [`items/`](../items/).

| Предмет | Когда | Что делает |
|---|---|---|
| **Картридж LEARN** | В чистую сессию | Обучение: теория, практика, мини-проверки. Только функции самого ассистента |
| **Картридж CO-OP** | В середину рабочей сессии | Помогает с текущей задачей и показывает Pro moves: как лучше и почему. Объяснения можно выключить |
| **Карта памяти** | В конце любой сессии | Итог, код сохранения, ссылка на сайт. Сессия закрывается только ей — не по времени и не по теме |

**Почему именно так:** надёжнее всего научиться в той же среде, которой хочешь пользоваться. Механика вставки проверена массовым кейсом Snickers Hungr.AI (август 2026).

## 5. Принятые решения

- Демо — **один ассистент: Claude Code**.
- Анкета в демо — **один путь**: остальные варианты видны, но неактивны.
- **Видео-демо** во второй части презентации: один пользователь, один ассистент, обе сессии (LEARN и CO-OP).
- **MCP-коннектор** — масштабирование (автоматизация сохранения), суть та же.
- Прогресс сохраняется **по коду** из карты памяти. Логин не нужен: ID игрока создаётся при анкете.
- Дизайн с отсылками к ностальгии, **без перебора**.
- Тексты предметов — на английском (продукт для США).

## 6. Что уже проверено

**Живой тест в Claude Code v2.1.280 (14 ноября):** обе сессии работают end-to-end.
- Картридж LEARN включает режим: экран загрузки, карта квестов, строка статуса в каждом ответе.
- ИИ проверяет реальное выполнение задания и не засчитывает невыполненное.
- Картридж CO-OP сразу разбирает уже сделанную работу и даёт Pro move по реальной проблеме.
- Одна карта памяти закрывает обе сессии и выдаёт код по формату (`SV1-P7K3Q-L-C0-P1-T0-Q1o2`), код проходит проверку шаблоном сайта.

**Не проверено:** окно подтверждения команды `open` и открытие браузера в интерактивном режиме; сайт ещё не создан.

## 7. Ограничения и риски

| Риск | Что известно / план |
|---|---|
| «Только веб» | Сайт веб, но вторая половина опыта — во внешнем ИИ-агенте. Claude Code есть в браузерной версии (claude.ai/code). Уточнить у организаторов |
| «Без регистрации и логина» | На сайте логина нет, но для работы с предметом нужен свой аккаунт ассистента. Подстраховка: пример кода сохранения, чтобы судья прошёл весь путь на сайте за 30 секунд |
| Ядро «не захардкожено» (40%) | Предметы должны реально генерироваться по анкете, а не быть заготовками |
| «Это просто промт» | Ответ: персонализация, прогресс, код, который нельзя подделать, обновления вслед за ИИ |
| Деньги (15%) | Предмет можно скопировать. Платят за программу, прогресс и свежие картриджи |
| Платформы сделают сами | У ChatGPT есть Study Mode, у Claude — Learning Mode, но они учат предметам, а не самому ассистенту. Аргумент: нейтральность к ассистенту |
| Claude Code — инструмент разработчика | В питче объяснить: это верхняя ступень, «свой Джарвис» |
| Тариф Max не даёт API-ключ | Для генерации через Claude API нужен отдельный ключ с балансом. Альтернатива — генерация по правилам из ответов анкеты |
| MCP | В Claude бесплатно доступен один свой коннектор. В ChatGPT полноценный режим — только Business/Enterprise |

## 8. Вопросы к организаторам

1. Подходит ли под «только веб» продукт, который генерирует контент для стороннего ИИ-ассистента? Claude Code в терминале — ок, или лучше браузерная версия?
2. Нормально ли, что для полного опыта нужен собственный аккаунт пользователя в ассистенте, если на нашем сайте логина нет?
3. Судьи сами проходят продукт или оценивают по питчу и демо?
4. Можно ли показать видео во время питча? Будет ли экран и звук? Можно ли дать ссылку на видео в PDF-деке?
5. Дают ли участникам кредиты на API?
6. Дедлайн — по местному времени? Куда и в каком виде сдавать? Язык питча и дека?
7. Смотрят ли судьи историю коммитов?
