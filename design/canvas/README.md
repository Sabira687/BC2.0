# Холст дизайна AIGO v5

Утверждённые макеты платформы и лендинга.

- `preview/` — самостоятельные HTML-страницы с кликабельными состояниями. Открываются в браузере через локальный сервер: `python3 -m http.server -d design/canvas/preview`.
- `boards/` — исходные доски холста (`*.dc.html`).
- `generators/` — скрипты, которые собирают доски: `python3 <generator>.py <папка с project/>`. Иллюстрации предметов — в `gen4_art.py`, общие стили — в `gen4_common.py`.

Решения по дизайну описаны в `spec/06-collection-v4-design.md` (§11–§12).
