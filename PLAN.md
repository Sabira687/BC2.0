## Цель

Основной сценарий в веб-приложении:
- пройти анкету;
- получить сгенерированные по анкете предметы;
- страница прогресса;
- страница коллекции предметов (для демо — 3 предмета);
- анимации и особый дизайн для пользовательского опыта и ностальгии;
- продуманный механизм создания предмета и обучения по нему (сам ИИ плохо составляет уроки и учебные пути);
- продуманный механизм сохранения прогресса: код для обучающей сессии и решение для сессии помощи.

> **Название продукта: AIGO Collection.**
>
> **Позиционирование (версия 3):** AIGO — **коллекция предметов, которые развивают навыки работы с ИИ**. Предметы различаются не только видом, но и сутью: у каждого свой режим (учиться, проверить себя, получить помощь, позже — мини-игры и задания на время). Пользователь выбирает режим и предмет. В демо три предмета: **LEARN · Module 1**, **TEST · Module 1** (тест, оценка, код результата → прогресс), **HELP**. Сейчас коллекция про навыки ИИ; концепция переносится на другие сферы.

## Изменения после FAQ организаторов

- Весь ключевой сценарий — **в браузере**: встроенная ИИ-консоль AIGO (Claude API) на отдельной полноразмерной вкладке; перенос предмета в настоящий Claude — дополнительная возможность.
- Ассистент демо — **Claude Chat**, Джон — офисный менеджер, растущий в карьере.
- Панель подсказок с готовыми ответами, чтобы жюри не застревало.
- **Пейвол** с понятной ценой (минимум), тестовая оплата Stripe — если успеваем.
- Видео-демо не делаем.
