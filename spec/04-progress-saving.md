# Прогресс

> Версия 3 — концепция коллекции. Прогресс больше не сохраняется в середине урока. Каждый предмет самодостаточен: вставил — работает. **Прогресс даёт предмет-тест**: он проверяет знания по модулю, ставит оценку и выдаёт код результата.

## Как прогресс попадает на сайт

1. Пользователь вставляет предмет **TEST · Module 1** в консоль AIGO (или в настоящий Claude).
2. ИИ проводит тест (см. [03-learning-design.md](03-learning-design.md), раздел «Предмет TEST»), оценивает каждое задание и в конце показывает экран результата:

```
 ╔══════════════════════════════════════╗
 ║  TEST COMPLETE ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ 86/100  ║
 ║  RANK: GOLD                          ║
 ╚══════════════════════════════════════╝
RESULT CODE: SV1-67VGT-…
```

3. Код результата попадает на сайт одним из двух путей: ИИ предлагает открыть ссылку `/result/<код>` или пользователь вставляет код в поле на странице прогресса.
4. Сайт расшифровывает код по секретной таблице токенов игрока и обновляет прогресс.

**Код:** `SV1-<игрок>-<токены>`. Токены: результат каждого задания теста (пройдено / нет), итоговый балл (диапазон), освоенные приёмы. ИИ только копирует токены, ничего не вычисляет. Механика токенов уже проверена вживую ([feasibility.md](feasibility.md)).

## Что видит пользователь после ввода кода

1. Анимация чтения результата.
2. Балл, ранг и разбор: какие задания пройдены, какие приёмы освоены.
3. Если балл ≥ 70 — модуль засчитан, в коллекции открываются следующие предметы (за пропуском).
4. Если ниже — совет вернуться к предмету LEARN и попробовать тест снова.
5. Достижение, если заработано.

**Ранги:** Bronze 50–69 · Silver 70–84 · Gold 85–100.

**Достижения демо:**

| Достижение | Когда |
|---|---|
| **Player One** | Создан первый предмет |
| **First Test** | Введён первый код результата |
| **Module Clear** | Модуль сдан на 70+ |

## Сессия помощи (HELP)

Прогресс не сохраняется. Помощь разовая.

## Хранение

Всё в памяти браузера посетителя: профиль, коллекция, результаты тестов, таблицы токенов. Джон заполнен заранее, есть кнопка сброса. Разные посетители друг другу не мешают.

## Если что-то пошло не так

| Ситуация | Что происходит |
|---|---|
| Код с ошибкой или чужой | «Результат не читается»: подсказка проверить код |
| Тот же код введён повторно | Ничего не меняется, «уже засчитано» |
| Тест пройден снова | Сохраняется лучший результат |
| Память браузера очищена | Начать заново (демо) |
