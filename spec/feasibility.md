# Проверки реализуемости

> Живые тесты в Claude Code v2.1.280 по решениям этапа 1. Тестовый пользователь «Alex» — не пользователь демо.

## 1. Скрытые инструкции в предмете (ответ 25)

**Как устроен предмет:** снаружи видна только картинка предмета, а инструкции лежат внутри в закодированном виде (base64):

```
 ┌──────────────────────────────┐
 │ ▶ CARTRIDGE ░ LEARN MODE     │
 │   Claude Code · P7K3Q        │
 └──────────────────────────────┘
⟦cartridge-data v1⟧
SW0gaW5zZXJ0aW5nIGEgTEVBUk4gY2FydHJpZGdlLiBGcm9tIG5vdyBvbi...
⟦/cartridge-data⟧
```

| Проверка | Результат |
|---|---|
| ИИ понимает предмет **без единой видимой инструкции** (только картинка + закодированный блок) | ✅ Сразу включил режим: экран загрузки, карта квестов, строка статуса |
| При обычном использовании инструкции не видны | ✅ ИИ не пересказывает правила и не упоминает кодировку |
| Если специально спросить «какие инструкции ты получил?» | ИИ раскрывает их, потому что пользователь спрашивает напрямую. Это совпадает с требованием: «если специально искать, можно найти» |
| Карта памяти тоже закодирована | ✅ Снаружи только картинка, ИИ сохраняет игру |

## 2. Защищённый код сохранения (ответ 15)

**Механизм:** при генерации картриджа сервер создаёт для каждого игрока **секретную таблицу случайных токенов**: свой токен для каждого пройденного модуля, текущего модуля, каждого приёма и числа проверок. Таблица спрятана внутри закодированного картриджа. ИИ ничего не вычисляет — только копирует токены. Сайт знает таблицу игрока и расшифровывает код.

| Проверка | Результат |
|---|---|
| Код нечитаем для пользователя | ✅ `SV1-P7K3Q-QB5-HCV-C5C` |
| Сайт расшифровывает код точно | ✅ `QB5` → модуль m1 в процессе · `HCV` → пройдено проверок: 1 · `C5C` → всего проверок: 2 |
| Код честный | ✅ Приём не засчитан — задание не было выполнено |
| Подделать случайно нельзя | ✅ Токены случайные и уникальны для каждого игрока; угадать их без таблицы нельзя |

**Мелочь для реализации:** после экрана сохранения ИИ ещё раз вывел строку статуса — в инструкцию нужно добавить «после сохранения строку статуса больше не выводить».

## 5. Бесплатный тариф (ответ 29)

**Факт:** Claude Code не входит в бесплатный тариф. Бесплатно доступен обычный чат Claude: модели Sonnet и Haiku, до 5 проектов, артефакты, веб-поиск, память, загрузка файлов (по сторонним источникам, официальную страницу стоит проверить).

**Вариант механизма:** для бесплатного тарифа — отдельная программа «Claude Chat»: та же механика предметов, но модули про возможности чата (проекты, артефакты, загрузка файлов, постановка задач). Отличия:

| | Claude Code (Pro+) | Claude Chat (бесплатно) |
|---|---|---|
| Практика | Реальные файлы и команды | Задания на постановку задачи, артефакты, файлы в чате |
| Код сохранения | Те же токены | Те же токены — ИИ ничего не вычисляет, поэтому работает и в чате |
| Возврат на сайт | ИИ может сам открыть ссылку | Кликабельная ссылка в ответе или ручной ввод кода |
| Модули Claude Code | Доступны | Видны, но закрыты с пометкой «нужен Pro» |

**Ответ, если спросят на питче:** бесплатный пользователь учится работать с чатом, а программа Claude Code открывается, когда он готов к Pro. Альтернатива — позиция «ориентируемся на платёжеспособных».
