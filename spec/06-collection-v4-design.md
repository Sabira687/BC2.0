# AIGO Collection v4: коллекционные карты навыков — дизайн

> Решение Капитана: концепция **B «Коллекционные карты навыков» + ритуал активации из A + книга марок из C**. Основание — исследование [../analysis/](../analysis/README.md).
> Документ заменяет механику прогресса версии 3 там, где они расходятся. Остальное из [02](02-item-generation.md), [03](03-learning-design.md), [04](04-progress-saving.md), [05](05-screens.md) остаётся в силе.

## 1. Зачем

Аудитория (офисные работники 28–33 в США, не технари, устали и тревожатся из-за ИИ) скучает по коллекционным играм своего детства: по **магии превращения** (Skylanders, Webkinz, чит-коды), по **видимому мастерству** (три звезды, голограмма), по ощущению **«это моё, и оно меня ждёт»** (Neopets) и по **учёбе, которую не замечаешь** (Neopets и HTML). Злится на коллекции-рычаги: случайность за деньги, серии и вину, пустые очки.

AIGO уже обладает «магией превращения»: вставил текст — ИИ стал наставником. v4 оформляет это как коллекцию карт, где каждая карта делает твой ИИ сильнее, а мастерство видно.

## 2. Цели, не-цели, анти-цели

**Цели**
- Коллекция карт разной сути, сгруппированных в наборы-навыки.
- Узнаваемый с детства «вау»: вставка карты = активация.
- Мастерство видно: звёзды, голограмма, марки, значок набора.
- Всё работает в браузере за 3 минуты у жюри и текстом внутри чата ИИ.
- Явное отличие от Coursiv: карты переносятся в свой Claude, нет серий и челленджей.

**Не-цели (после хакатона, в питч как дорожная карта)**
- Карты GAME и CHALLENGE (показываются как «скоро»).
- Звуки, карточка «поделиться», личное число «AI Level», обмен картами, другие сферы.

**Анти-цели (провал, даже если «работает»)**
- Случайные награды, лутбоксы, покупка карт поштучно.
- Серии, «не потеряй прогресс», стыдящие уведомления, FOMO, сгорающие карты.
- Очки, валюты, рейтинги, награды «за вход».
- Звёзды или марки без проверенного реального навыка.

## 3. Ограничения

- Демо — только браузер, консоль AIGO на Claude API; ассистент — Claude Chat; демо-игрок Джон.
- Внутри чата ИИ — только текст и разметка.
- Подсказки с готовыми ответами для жюри остаются.
- Два тарифа: **Free** (базовый путь, около 20 карт) и **Premium** $7 в месяц (полный путь, коннектор, ежемесячные карты). Демо для жюри — урезанный Free: только набор 01 из 3 карт. Подробно в §11.
- Стиль утверждён: тёмный космос, HUD-подписи, Barlow / IBM Plex; цвета и формы типов: LEARN ■ голубой, TEST ▲ маджента, HELP ● зелёный, закрытые ⬢ серые.
- Существующий код в `web/`: генератор предметов, токены и расшифровка кода, консоль, прогресс, достижения, Work chat, пейвол.

## 4. Подходы (рассмотрены в [../analysis/14-concept-brainstorm.md](../analysis/14-concept-brainstorm.md))

| Подход | Суть | Почему не он один |
|---|---|---|
| A. Power-up коды | Коллекция кодов, вставляешь — ИИ получает силу | Слабее визуально; слово «cheat» звучит как жульничество |
| **B. Карты навыков** ✅ | Карты LEARN / TEST / HELP в наборах, звёзды, голограмма, значок | Выбрана как основа |
| C. Паспорт навыков | Книга марок за реальные действия | Предметы уходят на второй план |

**Выбрано: B + ритуал активации из A + книга марок из C.**

## 5. Дизайн

### 5.1 Структура
```
VAULT 001 · AI SKILLS
FREE · БАЗОВЫЙ ПУТЬ: SET 01 · THE CLEAR ASK … SET 07 · PROJECTS (21 карта; в демо — только SET 01)
PREMIUM · ПОЛНЫЙ ПУТЬ: POWER USER (SET 08–11) · AUTOMATOR (SET 12–15) (+24 карты)
COMING SOON · GAME ⬢ · CHALLENGE ⬢
```
Набор = модуль = навык. Карта = предмет-режим (LEARN, TEST, HELP — как в v3).

### 5.2 Анатомия карты
Форма и цвет типа · символ набора и номер «1/3» · иллюстрация 4:5 · название · свойства (режим, время) · flavor text курсивом · звёзды 0–3 · голографическая версия.

### 5.3 Получение карт
- Набор 01: все три карты создаются сразу (без случайности, без покупки).
- Наборы 02–07 (Free) и наборы Premium: силуэты «???» на карте и в альбоме. В демо наборы 02–07 подписаны «Free · после демо», наборы Premium — «Premium».
- Создание карты — анимация раскрытия: силуэт → тряска и блик → свечение цвета типа → пауза ~0,8 с → вспышка → «NEW!» → карта встаёт в альбом, счётчик «докручивается». Кнопка «пропустить» для повторных.

### 5.4 Ритуал активации
- **В чате:** первая строка ответа ИИ на любую карту — `▶ ITEM ACTIVATED · <TYPE> · <название>`.
- **На сайте:** рамка поля ввода консоли вспыхивает цветом вставленной карты, над полем — мини-карта «<карта> inserted».

### 5.5 Звёзды (заменяют Bronze / Silver / Gold)
| Карта | ★ | ★★ | ★★★ |
|---|---|---|---|
| LEARN | урок 1.1 пройден | 1.1 + 1.2 | все 3 урока + финальное задание |
| TEST | 50+ | 70+ (модуль засчитан) | 90+ |
| HELP | без звёзд | | |

В чате: `✅ CHECK PASSED · ★★☆` (LEARN, после урока) и `TEST COMPLETE · ★★★ · 92/100` (TEST). Звёзды обеих карт попадают в код результата и на сайт.

### 5.6 Голографическая версия
TEST ★★★ → карта TEST и значок набора становятся голографическими (перелив по наклону и курсору).

### 5.7 Книга марок
- Марка = **проверенно применённый** приём (коды приёмов 1–9, A–C уже есть).
- В чате: `STAMP EARNED · <приём>` — только после проверки.
- На сайте: книга марок на странице прогресса; марки по сложности Easy / Medium / Hard (наборы 1–2 / 3–5 / 6–8); полная страница набора открывает иллюстрацию набора.
- **Подаренный прогресс:** марка «Player One» ставится при создании коллекции.

### 5.8 Значок набора
Условие: LEARN ★★★ + TEST ★★ и выше + HELP использован хотя бы раз. Награда: значок на полке, на карте навыков открывается следующий набор (с пропуском), реплика «хранителя».

### 5.9 Карта навыков
Наборы — точки-созвездия со звёздами; открытые можно проходить в любом порядке.

### 5.10 Удержание и деньги
Силуэты и счётчики · растущий Promotion Kit · новые карты вслед за обновлениями ИИ, старые не сгорают · без серий · базовый путь бесплатен навсегда · Premium $7 добавляет полный путь, коннектор и ежемесячные карты (§11).

### 5.11 Надписи
`▶ ITEM ACTIVATED` · `NEW!` / `YOU GOT A NEW CARD!` · `CHECK PASSED · ★★☆` · `STAMP EARNED` · `SET COMPLETE` · `ACHIEVEMENT UNLOCKED` · `??? · You'll see it later` · «Your cards wait for you.» Капслок — только в момент награды.

### 5.12 Достижения
Player One (первая карта), First Test (первый код результата), Set Clear (первый значок набора) — заменяет Module Clear.

## 6. Что меняется в реализации (объём демо)

1. **Генератор карт:** строка `▶ ITEM ACTIVATED` в начале ответа; звёзды вместо рангов в LEARN и TEST; строка `STAMP EARNED` после проверенного приёма; flavor text у карт.
2. **Код результата / расшифровка:** звёзды LEARN и TEST, марки (коды приёмов уже есть).
3. **Прогресс:** звёзды, марки, значок набора, голографическое состояние; Player One как подаренная марка; достижение Set Clear.
4. **Коллекция:** альбом по наборам, силуэты закрытых наборов, счётчики, анимация раскрытия, flavor text, голографическая карта.
5. **Консоль:** вспышка рамки поля ввода цветом карты и мини-карта «inserted»; звёзды и марки в интерфейсе подсказок.
6. **Тексты сайта:** «карты», «наборы», «активация»; карта переносится в свой Claude как главный сценарий; никаких серий и челленджей.

## 7. Остаётся на усмотрение исполнителя
Точные тайминги анимаций (в пределах ~300 мс на шаг), CSS-техника голограммы, формат токенов для звёзд и марок в коде результата, раскладка альбома на телефоне.

## 8. Решения исполнителя (Claude), которые стоит проверить
- Набор 01: все три карты сразу, без ожидания TEST после урока — ради скорости жюри.
- Условие значка набора — LEARN ★★★ + TEST ★★+ + HELP использован.
- Звёзды LEARN считаются по пройденным урокам, TEST — по баллам.
- Достижение Module Clear переименовано в Set Clear.

## 9. Вопросы к Капитану (после чтения глазами исполнителя)

**В1. Как звёзды LEARN и марки попадают на сайт без сохранения посреди урока?**
В v3 урок самодостаточен, код выдаёт только TEST. Но звёзды LEARN и марки нужно где-то засчитать.
- **Вариант 1 (рекомендую):** в консоли AIGO прогресс засчитывается **автоматически**: сайт видит строки ИИ `CHECK PASSED · ★★☆` и `STAMP EARNED` и сразу обновляет коллекцию, без кодов. В собственном Claude мостом остаётся только код результата TEST (в нём — звёзды TEST и марки).
- **Вариант 2:** LEARN в конце модуля тоже выдаёт код результата — одинаково в консоли и в своём Claude, но это ещё один шаг для пользователя.

**В2. Как жюри увидит значок набора и голограмму за 3 минуты?**
Полный набор (3 урока + финальное задание + тест + помощь) — 10+ минут.
- **Вариант 1 (рекомендую):** кнопка «Demo: fast-forward John» с пометкой «демо» — проводит те же данные через настоящую логику и показывает значок и голограмму (FAQ Q35 и Q66 это разрешают).
- **Вариант 2:** жюри видит только то, что успеет пройти, остальное — в деке.

## 10. Ответы Капитана (утверждено)

- **В1 → Вариант 1.** В консоли AIGO звёзды LEARN, марки и использование HELP засчитываются **автоматически**: сайт читает строки ИИ `CHECK PASSED · ★…`, `STAMP EARNED · …`, `▶ ITEM ACTIVATED · HELP`. В собственном Claude мост — код результата TEST (звёзды TEST + марки).
- **В2 → Вариант 1.** Кнопка **«Demo: fast-forward John»** с явной пометкой «демо» проводит данные через настоящую логику и показывает значок набора и голограмму.
- **Дизайн:** прежние указания по стилю отменены; новый визуальный язык строится на исследовании и концепции v4. **Не слишком игровой:** это образовательный продукт с коллекцией, а не игра.
- Документ утверждён.

### 11.1 Тарифы и масштаб

| **Free при запуске** | Базовый путь: 7 навыков, 21 карта (наборы 01–07); консоль AIGO и свой Claude; книга марок, коды, значки | Те же шаблоны урока и теста — новые наборы пишутся по библиотеке, без нового кода |

Демо работает на урезанном Free; Premium показан как продолжение и закрывает требование об оплате (тестовая оплата).

### 11.2 Предметы: история, иллюстрация, редкость
- Фигуры типов были заглушкой. У каждой карты — **свой предмет**: имя, мини-история (2–3 предложения, метафора приёма — работает как запоминалка) и цветная иллюстрация. Тип остаётся в цвете рамки и значке ■ ▲ ●.
- **Редкость** (ранжирование) — по глубине навыка, не случайно и не за деньги: ● Common (наборы 01–03), ◆ Rare (04–07), ★ Legendary (Premium). Голограмма — отдельно, за мастерство (TEST ★★★).
- Номер в коллекции: «S01 · 1/3», как у карточек TCG.
- Черновик набора 01 (Капитан может переписать):
  - LEARN · **Three-Tooth Key** — «Forged for doors that never open on the first knock. Its three teeth are who you are, what you need and how it should look. Miss one and the lock just spins.»
  - TEST · **Proving Lock** — «Five keyholes, no hints. It doesn't care how you learned, only whether your key is cut right.»
  - HELP · **Pocket Compass** — «It won't walk the road for you. Lost mid-task? It points once, toward one better move, then goes quiet.»
- Иллюстрации на холсте — концепт-арт исполнителя; финальные Капитан придумает позже.

### 11.3 Лучшее из старых игр — с фильтром
Берём только то, что служит **коллекционированию предметов** и **проверенному навыку**:

| Берём | Откуда | Зачем в AIGO |
|---|---|---|
| Раскрытие карты | паки Pokémon TCG, Hearthstone | Момент получения предмета (без случайности) |
| Редкость и номер в наборе | Pokémon TCG | Ранжирование предметов, видно масштаб коллекции |
| История предмета | записи Pokédex, flavor text | Метафора приёма, легче запомнить |
| Силуэты «???» и счётчик «seen / collected» | Pokédex | Видно, сколько ещё впереди |
| Активация на «портале» | Skylanders | Карта «оживает» в чате |
| Книга марок | Club Penguin | Доказательство применённых навыков |
| Голограмма за мастерство | золотые карты Hearthstone | Награда за качество, не за время |
| Секретный код | Webkinz, чит-коды | Код результата из своего Claude |

**Оставляем за бортом:** серии и ежедневные входы (чувство вины), случайные лутбоксы, таймеры и энергия, таблицы лидеров, внутреннюю валюту.

## 12. Платформа v5 (решения Капитана, 15 ноября)

- **Единый подход с лендингом**, но светлая тема: шрифты Barlow Condensed (заголовки, капсом) / IBM Plex Sans / IBM Plex Mono, срезанные углы у кнопок и панелей, моно-подписи «01 / COLLECTION», билеты и терминал как приёмы. Палитра платформы прежняя светлая.
- **Анкета** — как старая школьная анкета: тетрадный лист, разные поля (галочки, обвести, подчеркнуть, наклейки). Карандаш = демо-ответ (заблокирован), синие чернила = свой ответ. Открыты только имя (меняет обращение) и стиль Mentor / Straight talk. Справа — зачем заполнять: польза приложения.
- **Коллекция** — компактные наборы по 3 карты, видны все 45 предметов (21 Free + 24 Premium), заблокированные — силуэтами; карта приподнимается при наведении; яркий счётчик «3 / 45»; сортировка по набору / навыку / редкости (детали фильтров — позже).
- **Страница предмета** = раскрытая карта без самой карты: предмет парит сверху, ниже характеристики в стиле игровой подсказки (статы, «+ Stamp», «Use:», история), ниже — как использовать.
- **Уроки на платформе — только настройка** (страница Guide): завести Claude, скопировать предмет, вставить в новый чат, вернуть код результата, помощь посреди работы, коннектор (Premium). Само обучение — внутри ИИ.
- **Консоль** — настоящий терминальный чат. Вставленный предмет показывается как предмет (иллюстрация, имя), инструкции внутри. Ответы ИИ оформлены текстовыми рамками:
  - заголовок урока между линиями `━━━`, прогресс `step 4/7 ████░░░`;
  - блоки «открытая справа рамка»: `┌─ YOUR TURN ───` / `│ текст` / `└──────` (правой границы нет — так ровно и в моноширинном терминале, и в обычном шрифте claude.ai);
  - чек-лист `[✓] format · 3 bullets`, выбор `[1] next lesson  [2] more practice`;
  - строки событий без изменений: `▶ ITEM ACTIVATED`, `✅ CHECK PASSED · ★★☆`, `✦ STAMP EARNED · …`, `HELP USED`, `TEST COMPLETE`, `RESULT CODE: …`.
- **Прогресс** — «небо навыков» по образцу созвездий навыков Skyrim: каждый набор — созвездие (набор 01 — в форме ключа), каждая звезда — проверенный шаг (уроки, финал, тест, помощь, значок). Книга марок — билет-паспорт как в музеях: одна сетка без деления по этапам, обводка по сложности: старт — серая, easy — зелёная, medium — жёлтая, hard — красная.
- **Результат теста** — в чате рамка TEST COMPLETE с таблицей заданий и RESULT CODE; на сайте после вставки кода — визуал: голографический предмет, счёт, звёзды, задания ✓/✗, «One thing to practice».
- **Premium** — три билета (демо / Free / Premium) с пометками «WHY IT'S REAL», пути Power user и Automator, тестовая оплата «ADMIT ONE».
