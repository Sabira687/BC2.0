# Экраны

> Итог этапа 1 по [01-user-journey.md](01-user-journey.md). Вход для этапа 2 (дизайн).

## Страницы

| # | Экран | Назначение | Ключевые элементы |
|---|---|---|---|
| 1 | **Главная** `/` | Рассказать о продукте и позвать начать | Визуал, суть продукта в 1–2 фразах, как это работает (3 шага: анкета → предмет → учишься в ИИ), короткая памятка, кнопка «Начать» |
| 2 | **Анкета** `/start` | Собрать данные игрока | Поля из [02-item-generation.md](02-item-generation.md); в демо всё заполнено за Джона, другие варианты видны, но неактивны; кнопка «Начать» |
| 3 | **Прогресс** `/progress` — главная после анкеты | Показать, где игрок и что делать дальше | Карточка игрока · квесты знакомства с платформой (0–3) · карта модулей ✓ / ▸ / · · открытые приёмы · достижения · **поле для кода сохранения** · кнопка сброса |
| 4 | **Коллекция** `/collection` | Собирать предметы | Типы предметов с разной сутью: LEARN · TEST · HELP (в демо) и MINI-GAME · CHALLENGE («скоро», без кнопок) · свойства предмета: режим, модуль, время · сначала закрыты, создаются по одному · за пропуском — следующие модули |
| 5 | **Страница предмета** `/item/learn`, `/item/test`, `/item/help` | Объяснить и выдать предмет | Визуал предмета · описание · инструкция «когда и куда вставлять» · кнопка «Копировать» |
| 6 | **ИИ-консоль** `/console` — отдельная полноразмерная вкладка | Пройти урок прямо в браузере | Окно чата в стиле Claude на весь экран · вставка предмета · **панель подсказок**: что делать сейчас + готовый ответ с кнопкой «Копировать» · строка статуса · кнопка «Перенести в настоящий Claude» (копирует предмет и открывает инструкцию) |
| 7 | **Пейвол** | Показать, за что платят | Первый модуль бесплатно, дальше подписка **$7 в месяц** · тестовая оплата (Stripe test mode, если успеваем) · пометка «демо» |
| 8 | **Результат теста** `/result/<код>` | Принять код и показать результат | Анимация чтения → балл и ранг → разбор заданий → освоенные приёмы → открывшиеся предметы → достижение → на страницу прогресса |

## Всплывающие элементы

| Элемент | Когда |
|---|---|
| **Анимация создания предмета** | Нажатие на закрытую ячейку в коллекции |
| **Достижение получено** | Player One, First Test, Module Clear |
| **Квест выполнен** | Выполнен шаг из квестов знакомства |
| **«Скопировано»** | Кнопка «Копировать» на странице предмета |
| **Ошибка кода** | Код не читается или уже сохранён |

## Квесты знакомства с платформой

| # | Квест | Выполнен, когда |
|---|---|---|
| 0 | Осмотри коллекцию | Открыта страница коллекции |
| 1 | Создай предмет обучения | Создан LEARN · Module 1 |
| 2 | Пройди тест | Создан TEST · Module 1 и введён первый код результата |
| 3 | Получи помощь | Создан HELP |

## Вне экранов сайта (в ИИ-ассистенте)

Для дизайна предметов тоже нужен визуал внутри чата:
- картинка каждого из трёх предметов (как она выглядит при вставке);
- экран загрузки картриджа;
- строка статуса;
- экран сохранения.
