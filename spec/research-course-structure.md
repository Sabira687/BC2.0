# Как устроены уроки на популярных курсах по ИИ

## 1. Разбор курсов

| Курс | Объём | Структура | Формат урока | Проверка |
|---|---|---|---|---|
| **Claude Code in Action** (Anthropic Academy) | ~1 час видео | 4 блока по возрастанию: **«Управляй работой» → «Настрой Claude» → «Автоматизируй повторяющееся» → «Проверяй и делись»**. Темы: длинные сессии, CLAUDE.md, проверка результата, режимы разрешений, хуки, фоновые и headless-запуски, GitHub Actions, плагины | Короткое видео + практика в своём проекте | Квиз после блоков и итоговый квиз |
| **AI Fluency: Framework & Foundations** (Anthropic Academy) | 14 уроков, ~4 часа | Основа — **рамка 4D**: **Delegation** (что поручать ИИ), **Description** (как ставить задачу), **Discernment** (как оценивать ответ), **Diligence** (ответственность за результат). Сначала как устроен генеративный ИИ и где он ошибается, потом по одному D, в конце сертификат | Объяснение + упражнения с любым ассистентом | Итоговая проверка, бейдж |
| **Google AI Essentials** (Coursera) | 5 модулей, ~6–10 часов | Введение в ИИ → продуктивность с ИИ-инструментами → искусство промтов → ответственное использование → как не отстать от ИИ | **Видео 2–8 минут** + практическое упражнение (иногда диалог с чатботом) | **Проверка знаний с оценкой** в конце модуля, сертификат |
| **ChatGPT Prompt Engineering for Developers** (DeepLearning.AI) | 9 уроков, ~1.5 часа | Принципы промтов → итерации → суммаризация → извлечение смысла → преобразование текста → … | **Видео 6–17 минут + живой пример кода**, который можно сразу запустить и изменить | Нет оценки — практика в примерах |

Отзывы о Google AI Essentials: курс вводный, практика лёгкая, а не полноценные проекты.

## 2. Общие закономерности

1. **Короткие единицы.** Урок — 2–17 минут, модуль — до часа.
2. **Порядок внутри урока:** зачем это нужно → объяснение → пример → попробуй сам → проверка.
3. **Порядок модулей — от простого к автономному:** базовое управление → настройка под себя → автоматизация → проверка и ответственность за результат.
4. **Каркасная идея.** У сильных курсов есть одна рамка, на которую нанизаны все уроки (у Anthropic — 4D).
5. **Проверка в конце модуля:** квиз или итоговое задание; в конце курса — сертификат или бейдж.
6. **Практика на «живом» материале:** у DeepLearning.AI — запускаемый код, у Anthropic — свой проект.

## 3. Что говорят исследования об обучении

| Принцип | Суть | Источник |
|---|---|---|
| **Затухающие примеры** | Сначала полностью разобранный пример → потом задача, где часть решения дана → потом задача целиком | Paas & van Merriënboer, 1994 |
| **Практика извлечения** | Вспомнить и применить самому полезнее, чем перечитать объяснение | Karpicke, 2011 (Science) |
| **Интервальное повторение** | Возвращаться к пройденному через время, в разных сценариях | Обзоры по Gagné |
| **Цель в начале урока** | Взрослый сразу хочет знать, что он получит от урока; ясная цель повышает внимание и доводимость | Практические руководства по Gagné |
| **Девять событий обучения (Gagné)** | Привлечь внимание → цель → вспомнить прошлое → материал → помощь (примеры) → практика → обратная связь → оценка → закрепление. Это **чек-лист для планирования**, а не обязательная последовательность: доказаны отдельные элементы (практика, обратная связь), а не порядок целиком | Обзоры по Gagné |

## 4. Что из этого технически возможно внутри картриджа

| Элемент | Реализуемость |
|---|---|
| Цель урока в начале | ✅ Пишется в библиотеке урока, ИИ проговаривает |
| Разобранный пример → задача с частью решения → задача целиком | ✅ Все три шага задаются в библиотеке, ИИ ведёт по ним |
| Практика на реальном материале | ✅ Проверено: ИИ создаёт файлы в `./dojo` и проверяет результат |
| Проверка с оценкой | ✅ Проверено: ИИ считает проверки и не засчитывает невыполненное |
| Интервальное повторение | ✅ Картридж пересобирается после каждого сохранения → в начало новой сессии можно добавить короткое повторение прошлого модуля |
| Квиз в конце модуля | ✅ Выбор вариантов кнопками в приложении Claude |
| Сертификат / бейдж | ✅ На сайте, по коду сохранения (достижения уже в плане) |
