## Что меняется от пользователя к пользователю

| Часть картриджа | От чего зависит |
|---|---|
| Обращение | Имя |
| Набор модулей | Цель |
| Стартовый модуль | Текущий уровень |
| Сквозной проект | Зачем учится (рост в работе → Promotion Kit) |
| Количество «Watch me» | Текущий уровень |
| Тон ведения | Стиль |
| Размер заданий | Тариф |
| Состояние программы (✓ / ▸ / ·) и повторение «Previously on…» | Прогресс из последнего кода сохранения |
| Таблица токенов сохранения | Случайно для каждого игрока |

## Механизм сборки

Генерация **по правилам**, без обращения к внешнему ИИ: ответы анкеты → программа → текст картриджа. Разные ответы дают разные картриджи — ядро не захардкожено.

1. **Библиотека** (заранее написанные данные): модули, уроки, задания, проверки, вопросы, таблица Pro moves, блоки тона для трёх стилей, сквозные проекты.
2. **Профиль** из анкеты + **прогресс** из последнего сохранения.
3. **Сборщик** отбирает модули под цель, определяет стартовую точку, подставляет проект, тон и размер заданий, создаёт таблицу токенов игрока.
4. **Текст картриджа** собирается из шаблона.
5. **Упаковка:** текст кодируется (base64) и оборачивается в картинку предмета. Снаружи видна только картинка.

Всё происходит в браузере пользователя. Профиль, прогресс и таблица токенов хранятся там же — поэтому сайт может расшифровать код сохранения без сервера и без логина.

## Три предмета

| Предмет | Что внутри (скрыто) | Когда пересобирается |
|---|---|---|
| **Картридж LEARN** | Профиль, программа с отметками прогресса, уроки текущего модуля, повторение прошлого модуля, правила ведения урока, таблица токенов, экран сохранения | После каждого ввода кода сохранения — незаметно для пользователя |
| **Карта памяти** | Команда: завершить активный картридж и показать его экран сохранения | Не меняется |
| **Картридж CO-OP** | Профиль, таблица «ситуация → Pro move», правило «разовая помощь, потом отключиться» | При смене анкеты |

| | **Джон**, 29 | **Мария**, 32 (для сравнения) |
|---|---|---|
| Уровень → старт | Только чатбот → с m1, все «Watch me» | Пробовала агента → с m2, «Watch me» по запросу |

| Тариф | Pro: компактные задания | Max: без ограничений |
