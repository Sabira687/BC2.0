# Webkinz (2005–): мягкая игрушка + секретный код

## Факты
- Плюшевые игрушки Ganz, у каждой на бирке — **секретный код**. Его вводят на сайте и «усыновляют» онлайн-версию питомца **[Wikipedia]**.
- Браузерная игра детства миллениалов. Сейчас переживает возрождение: миллениалы и зумеры 20–40 лет заходят в свои детские аккаунты, TikTok полон ностальгии **[Rolling Stone, Ypulse]**.

## Механика
| Элемент | Как работает |
|---|---|
| Что коллекционируют | Питомцев (каждая игрушка — новый), мебель, одежду, комнаты |
| Ключевое действие | **Ввести код с бирки → питомец оживает в онлайн-мире** |
| Доступ | Код даёт год полного доступа; без кода — бесплатный аккаунт с ограничениями **[Wikipedia]** |
| Формат кода | Сначала 8 знаков, после 2020 — два кода: 8 знаков для Classic и 15 для Next **[Wikipedia]** |
| Игровой цикл | Мини-игры → валюта (KinzCash) → вещи для питомца и комнаты |

## Изюминка
1. **Код как мост между физическим и цифровым.** Ты держишь в руках игрушку, и у неё есть «душа» в сети.
2. **Питомец ждёт тебя.** Возвращаешься — он на месте.
3. **Коллекция живых существ**, а не значков: «так много зверей для коллекции» **[Daily Targum]**.

## Дизайн
- Плюшевый и уютный мир; у каждого питомца своя комната **[≈]**.
- Бирка-сердечко с кодом на игрушке — узнаваемый физический элемент **[≈]**.

## Голос игроков
**Скучают:**
- Возвращаются в детские аккаунты «за эмоциональной поддержкой»; цифровая ностальгия как утешение для этих поколений **[Ypulse]**.

**Жалуются:**
- «Почему я должен платить, если в детстве играл бесплатно?» — частый вопрос в комментариях к новостям Webkinz **[Webkinz Newz]**.
- «Теперь ничего нет бесплатно» **[Daily Targum]**.

## Перенос на AIGO
| Берём | Почему |
|---|---|
| **Код, который «оживляет» предмет** | Ровно наша механика: вставляешь блок текста — и ИИ получает «душу» наставника. Webkinz доказывает, что аудитории 28–33 эта механика знакома с детства |
| **Предмет ждёт тебя** | Коллекция и прогресс хранятся; вернулся — всё на месте |
| **Код как часть предмета** | Код результата теста — тот же жест в обратную сторону: ИИ выдаёт код, ты вносишь его на сайт |
| **Не берём:** ощущение «раньше было бесплатно, теперь отобрали» | Бесплатное ядро (модуль 1) не отбирать; пропуск открывает новое, а не возвращает старое |
