# Фаза 4. Как паттерны ложатся на AIGO

## 1. Что есть сейчас (версия 3)

- **Предметы:** LEARN · Module 1 (квадрат, синий), TEST · Module 1 (треугольник, маджента), HELP (круг, зелёный); закрытые «??? · You'll see it later» (шестиугольники).
- **Механика:** предмет вставляется в консоль AIGO (Claude API) или в свой Claude → ИИ ведёт урок, тест или даёт разовую помощь. Тест выдаёт код результата → прогресс, ранг Bronze / Silver / Gold, достижения Player One / First Test / Module Clear.
- **Прочее:** путь из 8 модулей; пропуск $7 в месяц; подсказки для жюри; Work chat для помощи.
- **Стиль:** тёмный космос, HUD-подписи, Barlow / IBM Plex, голографический перелив на предметах.

## 2. Ограничения

| # | Ограничение | Следствие для паттернов |
|---|---|---|
| О1 | **Внутри чата ИИ — только текст и разметка** | Всё, что происходит в чате, должно работать строкой текста: ★★☆, «ITEM ACTIVATED», «STAMP EARNED». Анимации, альбом, карта — только на сайте |
| О2 | **Всё в браузере, жюри за 3 минуты** | Момент «вау» должен случиться быстро: вставка предмета → мгновенное превращение |
| О3 | **Учебная цель** | Каждая игровая деталь привязана к реальному навыку (урок Foursquare и Duolingo) |
| О4 | **Аудитория 28–33, не технари, устала, тревожится из-за ИИ** | Никакого давления и вины; ИИ как союзник, «технологии снова обнадёживают» |
| О5 | **Жюри:** продление подписки, механика возврата в продукте, новизна против Coursiv | Нужен повод платить месяцами, а не каждый день |
| О6 | **Утверждённый стиль** | Ностальгию передаём предметами и моментами, а не перекраской сайта |

## 3. Вердикт по каждому паттерну

| Паттерн | Вердикт | Как в AIGO | Где видно |
|---|---|---|---|
| **P1 Активация** | ✅ **Ядро, усилить** | Вставка предмета = «активация»: ИИ отвечает строкой «▶ ITEM ACTIVATED · LEARN · The Clear Ask» и превращается. На сайте поле ввода консоли — «портал», который светится цветом типа, когда в него вставлен предмет | Чат + сайт |
| **P2 Предмет несёт состояние** | ✅ Уже есть, назвать вслух | Предмет хранит игрока, модуль, стиль, токены. Можно показать: «это твой экземпляр, он помнит тебя» | Сайт |
| **P3 Ожидание до раскрытия** | ✅ Взять без денег | Создание предмета: блик → свечение цвета типа → пауза → вспышка → «NEW!» | Сайт |
| **P4 Альбом с силуэтами** | ✅ Есть, развить | Сетка по наборам (модулям), силуэт формы закрытого предмета, счётчик «3 / 5», звезда на собранном наборе | Сайт |
| **P5 Набор → награда** | ✅ Взять | Набор = модуль. LEARN + TEST (+ HELP использован) → **значок модуля** | Сайт |
| **P6 Марки за действия** | ✅ **Взять — новое** | **Stamp Book** приёмов: марка за каждый реально применённый приём (сформулировал запрос по формуле, дал свой материал…). Сложность Easy / Medium / Hard | Чат (строка «STAMP · Brief Formula») + сайт (книга) |
| **P7 Оценка мастерства** | ✅ Упростить | **Три звезды** вместо Bronze / Silver / Gold: проще, узнаваемее, работает текстом ★★☆ | Чат + сайт |
| **P8 Карта пути** | ✅ С выбором | Карта навыков: открытые наборы можно проходить в любом порядке (урок Duolingo) | Сайт |
| **P9 Предмет = инструмент** | ✅ **Ключевое** | Каждый предмет делает ИИ полезнее в работе, и это видно сразу: Promotion Kit растёт | Чат + сайт |
| **P10 Альманах** | ✅ Взять | У предмета короткая смешная фраза-описание и «когда использовать» | Сайт |
| **P11 Фольга за качество** | ✅ Взять | Три звезды → **голографическая** версия значка или предмета | Сайт |
| **P12 Наставник с характером** | ✅ Есть | Mentor / Straight talk; без «стыдящей совы» | Чат |
| **P13 Учёба в игре** | ✅ **Позиционирование** | «Neopets научил поколение HTML. AIGO научит его ИИ» | Лендинг, питч |
| **P14 Значки за реальную жизнь** | ✅ Взять | Марки и значки за **действия на работе**, не за клики | Сайт |
| **P15 Личное число** | ⚠️ Осторожно | «AI Level» или число марок — только если растёт от реальных навыков, а не от активности | Сайт |
| **P16 Мир ждёт тебя** | ✅ Принцип | Никаких серий, никакой вины; «твои предметы ждут тебя» | Везде |
| **P17 Звуки** | ⚠️ По желанию | Короткий звук активации и звезды, с выключателем | Сайт |
| **P18 Aero-надежда** | ⚠️ Как акцент | Глянцевый блик на предметах; тексты про ИИ как союзника | Предметы, тексты |

## 4. Анти-паттерны и ответ AIGO

| Анти-паттерн | Ответ AIGO |
|---|---|
| Случайность за деньги | Предметы **не случайны** и **не продаются поштучно** |
| Плата за каждый предмет | Один пропуск $7 в месяц — вся коллекция |
| Серии и вина | Нет серий, нет стыдящих уведомлений |
| Отнятый выбор | Карта с выбором набора |
| Очки без смысла | Звёзды и марки только за проверенный реальный навык |
| FOMO | Предметы не сгорают; новые выходят, старые остаются |
| «Раньше было бесплатно» | Модуль 1 бесплатен всегда |
| Ненадёжная проверка | Подсказки с готовыми ответами; проверка по ясному чек-листу |
| Активность ≠ результат | Меряем результат: написанный запрос, готовый документ |

## 5. Совместимость с консолью ИИ: что видно в чате

Внутри чата (консоль AIGO и свой Claude) — только текст. Предмет должен давать «вкус игры» строками:

```
▶ ITEM ACTIVATED · LEARN · The Clear Ask
Coach mode on. Hi John!
…
✅ CHECK PASSED · ★★☆
STAMP EARNED · Brief Formula (Easy)
```

```
▶ ITEM ACTIVATED · TEST · Module 1
Task 4 of 5 …
TEST COMPLETE · ★★★ · 92/100
RESULT CODE: SV1-…
```

```
▶ ITEM ACTIVATED · HELP
⚡ ONE BETTER MOVE · Say it once, with all three parts
…
HELP USED · item returns to your collection
```

На сайте эти же события становятся анимацией: активация — свечение «портала», звёзды вылетают по одной, марка шлёпается в книгу.
