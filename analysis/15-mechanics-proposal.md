# Фаза 5.3. Предложение по механикам (рекомендованная концепция)

> Предложение, а не решение. Опирается на [10-patterns.md](10-patterns.md), [11-player-voice.md](11-player-voice.md), [13-fit-with-aigo.md](13-fit-with-aigo.md).

## 1. Структура коллекции

```
VAULT 001 · AI SKILLS
└── SET 01 · THE CLEAR ASK          (бесплатно, демо)
    ├── LEARN card   ■   теория + практика
    ├── TEST card    ▲   оценка → звёзды → код результата
    └── HELP card    ●   разовая помощь в работе
└── SET 02 · ITERATE                (пропуск)
└── …
└── SET 08 · ARTIFACTS
Скоро: GAME cards ⬢ · CHALLENGE cards ⬢
```

- **Набор = модуль = навык.** Названия уже есть (m1–m8).
- **Карта = предмет-режим.** Сохраняется решение версии 3: предметы отличаются сутью.

## 2. Как получают карты

| Карта | Как открывается | Почему так |
|---|---|---|
| LEARN | Сразу, при создании коллекции | Вход без барьера |
| TEST | Видна силуэтом «??? · откроется после первого урока» → открывается после урока 1.1 | Ожидание и силуэт (Pokémon), но короткое: урок с подсказками ~2 минуты |
| HELP | Сразу | Полезна с первого дня |
| Карты наборов 2–8 | Силуэты на карте; открываются с пропуском | Повод платить — открыть свою дорогу |

> **На решение Капитана:** если для жюри важна скорость, TEST можно открыть сразу, а силуэт оставить только для наборов 2–8.

Без случайности, без покупки поштучно, без дублей.

## 3. Ритуал активации

1. Человек вставляет карту в консоль (или в свой Claude).
2. **В чате:** первая строка ответа ИИ — `▶ ITEM ACTIVATED · LEARN · The Clear Ask`, затем режим включается.
3. **На сайте:** поле ввода консоли — «портал»: при вставке карты рамка вспыхивает цветом её типа, рядом появляется мини-карта «вставленный предмет».

Основание: Skylanders (портал), Webkinz (код оживляет), чит-коды («CHEAT ACTIVATED»).

## 4. Звёзды мастерства (вместо Bronze / Silver / Gold)

| Карта | ★ | ★★ | ★★★ |
|---|---|---|---|
| LEARN | Урок 1.1 пройден | Уроки 1.1 и 1.2 | Все 3 урока + финальное задание |
| TEST | 50+ баллов | 70+ (модуль засчитан) | 90+ |
| HELP | Без звёзд (инструмент) | — | — |

- Работает текстом в чате: `★★☆`.
- Основание: Angry Birds (переигрывать ради трёх звёзд), трофеи.

## 5. Голографическая версия

- **TEST ★★★ → голографическая карта TEST и голографический значок набора.**
- Основание: голо-карты Pokémon, золотые карты Hearthstone, фольга Steam. Редкость за мастерство, а не за деньги.

## 6. Книга марок

- **Марка = реально применённый приём.** Коды приёмов 1–9, A–C уже есть в генераторе и в коде результата.
- ИИ ставит марку, когда **проверил**, что приём использован: `STAMP EARNED · Brief Formula`.
- **Сложность** по набору: Easy (наборы 1–2), Medium (3–5), Hard (6–8).
- **Фото за полную страницу** (Club Penguin): все марки набора → открывается иллюстрация набора.
- Основание: Club Penguin, Brain Age, Foursquare.

## 7. Значок набора

- **Условие:** LEARN ★★★ + TEST ★★ и выше + HELP использован хотя бы раз.
- **Награда:** значок набора на полке + на карте открывается следующий набор + реплика «хранителя».
- Основание: значки Steam, связки Stardew.

## 8. Карта навыков с выбором

- Наборы — точки на звёздной карте, у каждой — звёзды.
- С пропуском можно идти **в любом порядке** (урок Duolingo: отнятый выбор бесит).

## 9. Удержание и деньги

| Механика | Зачем |
|---|---|
| Силуэты и счётчик «3 / 24» | Видимая незаконченность (Покедекс) |
| **Новые карты вслед за обновлениями ИИ** («новая функция Claude → новая карта») | Повод продлевать: ИИ меняется, коллекция растёт. Старые карты не сгорают — без FOMO |
| Promotion Kit копится | Реальная польза, не активность |
| **Никаких серий и стыдящих уведомлений** | Главная жалоба на Duolingo |
| Набор 01 бесплатен навсегда | Урок Webkinz: «раньше было бесплатно» |
| Пропуск $7 открывает наборы 2–8 и новые типы карт | Одна плата за всё, без поштучных покупок |

## 10. Позиционирование

- «The collection people miss, without the loot boxes they hated.»
- «Neopets taught a generation HTML. AIGO teaches them AI.»
- «Every card makes your AI stronger. Nothing is random. Nothing expires.»

## 11. Что менять в текущей реализации

**Обязательно для демо (бóльшая польза за малое время):**
1. Строка `▶ ITEM ACTIVATED · …` в начале ответа на каждую карту (правка генератора предметов).
2. Звёзды вместо рангов в TEST и в LEARN (генератор + страница результата + прогресс).
3. Марки из уже существующих кодов приёмов: строка `STAMP EARNED` в чате + книга марок на странице прогресса.
4. Значок набора и голографическая версия за ★★★.
5. Альбом коллекции: наборы, силуэты, счётчик, flavor text у карт.
6. «Портал» в консоли: свечение рамки цветом карты при вставке.

**Можно после хакатона (в питч как дорожную карту):**
GAME и CHALLENGE карты, звуки, карточка «поделиться», личное число «AI Level», другие сферы (языки, деньги).

## 12. Поправки после проверки психологией и Coursiv

Из [17-why-it-works.md](17-why-it-works.md) и [18-vs-coursiv.md](18-vs-coursiv.md):

1. **Подаренный прогресс.** Книга марок начинается не с нуля: марка **«Player One»** ставится при создании коллекции, набор 01 сразу показывает «1 / 3» после первой карты. Карточки с уже поставленными штампами заполняют охотнее (Nunes & Drèze, 2006).
2. **Сюжет важнее очков.** Метаанализ 2026: сюжетная геймификация работает сильнее очков и значков. Звёзды и марки показываем как главы истории Джона (Promotion Kit), а не как отдельную гонку очков.
3. **Награды — информация о мастерстве**, а не плата за действие: никаких очков «за вход», валют, рейтингов.
4. **Отличие от Coursiv на виду.** Главный сценарий — карта переносится в свой Claude; консоль AIGO — «примерочная». Никаких серий, челленджей «на N дней», сертификатов.
