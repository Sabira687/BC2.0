# Визуальный стиль коллекционных игр ~2013–2018

> **[источник]** — проверено в этой сессии. **[≈]** — общеизвестно, свежей проверки нет.

## 1. Эпоха: плоский дизайн + «вещи с весом»

- **Мобильный интерфейс 2015–2016 — плоский:** простые формы, гармоничные цвета, чистый UI, минимум шагов **[The Next Web, Coherent Labs, IndieGameBuzz]**.
- **Но коллекционные предметы делали «вещами»:** сундуки, наборы карт, коробки — объёмные, с текстурой, рамкой, бликом. Осторожный возврат скевоморфизма: «объекты плоские, но у них есть физическое присутствие» **[Creative Bloq, 2015]**.
- **Итог эпохи:** плоский, спокойный интерфейс вокруг и яркие, «осязаемые» предметы в центре. Предмет — главный визуальный герой экрана.

## 2. Цвет как язык редкости

| Уровень | Цвет | Пример |
|---|---|---|
| Обычный | Белый / серый, без свечения | Hearthstone, Overwatch **[PC Gamer, Overwatch Wiki]** |
| Редкий | Синий / голубой | Hearthstone, Overwatch |
| Эпический | Фиолетовый / розовый | Hearthstone, Overwatch |
| Легендарный | Оранжевый / золотой | Hearthstone, Overwatch, Diablo, WoW **[Game Informer]** |

- Шкала стала **общим языком игроков**: оранжевое свечение понятно без подписи **[GiantBomb, Mein-MMO]**.
- Единого стандарта нет: Borderlands добавлял свои оттенки, Grim Dawn шёл своим путём **[GiantBomb, форум Crate]**.

## 3. Фольга, голограмма, «золото»

- **Голографическая карта** — главный знак редкости детства: в первом наборе Pokémon только 16 из 102 карт были голографическими **[ExpertBeacon]**.
- **Притяжение фольги:** картинка «двигается» под светом, ощущается в руке, служит статусом на школьном дворе **[Aura Print, cardcodex]** (источники среднего качества).
- **Цифровые аналоги:** фольгированные карточки Steam со своим значком **[Steamworks]**, золотые анимированные карты Hearthstone **[≈]**.

## 4. Альбом коллекции

- **Сетка ячеек:** найденное — в цвете, ненайденное — чёрный силуэт с «???» **[allthings.how, Starbounder]**.
- **Счётчик по разделам** («66%», «47/151») и **звезда / отметка** на вкладке полностью собранного раздела **[Starbounder]**.
- **На закрытых ячейках оставляют намёк** (редкость, где искать), чтобы было понятно, что искать дальше **[allthings.how]**.

## 5. Типографика и рамки [≈]

- Крупные жирные заголовки с обводкой и тенью на кнопках и наградах («VICTORY!», «LEGENDARY»).
- Предметы в рамках: у карт — рамка по редкости, у сундуков — окантовка металлом, у значков — круглая медаль.
- Пиксель-арт и ретро-шрифты в инди (Stardew Valley, Shovel Knight) как ностальгия по 8–16 бит.
