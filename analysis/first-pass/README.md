## Главное за минуту

1. **Сила коллекции — в ожидании, а не в награде.** Свечение цвета редкости до раскрытия, тряска, пауза, вспышка.
2. **Цвет — универсальный язык ценности:** серый → синий → фиолетовый → оранжевый/золотой.
3. **Альбом с силуэтами «???» и счётчиком** превращает пустоту в интригу.
4. **Скучают по ощущению:** «моё, собрал сам, с друзьями, без давления, вещи ждали меня».
5. **Злятся на коллекцию как рычаг для денег:** случайность за деньги, FOMO, обязательные ежедневные входы, пустой гринд, корпоративный тон.
