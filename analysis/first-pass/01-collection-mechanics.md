# Механики коллекционирования в играх ~2013–2018

> **[источник]** — проверено в этой сессии (ссылки в конце). **[≈]** — общеизвестно, свежей проверки нет.

## 1. Разбор игр

| Игра (год) | Что коллекционируют | Ключевая механика | Почему цепляло |
|---|---|---|---|
| **Hearthstone** (2014) | Карты | Наборы по 5 карт, редкость по цвету свечения; защита от дублей и «таймер жалости» — шанс легендарки растёт с каждым пустым набором | Ожидание: рубашка карты светится цветом редкости ещё до переворота **[PC Gamer, Hearthstone Wiki]** |
| **Clash Royale** (2016) | Карты из сундуков | 4 слота под сундуки, у каждого таймер открытия; бесплатный сундук раз в 4 часа (копится до 2); порядок сундуков заранее задан циклом, а не случаен | Сессии, которые возвращают игрока каждый день; новые карты открываются по уровням арен **[Game Developer, mobilefreetoplay]** |
| **Overwatch** (2016) | Скины, эмоции, реплики | Лутбокс: коробка трясётся, раскрывается, предметы взлетают и падают по одному; редкость подсказывает цветная полоса света до раскрытия | «Всё строится на ожидании» — дизайнер Джереми Крейг **[Kotaku, PC Gamer]** |
| **Pokémon GO** (2016) | Покемоны | Покедекс — «поймай всех»; бадди-покемон даёт конфеты за пройденные километры | Коллекция наследует ценность, которую франшиза копила десятилетиями; сам процесс собирания приятен **[Game Developer, Medium, Pokémon GO Hub]** |
| **Steam Trading Cards** (2013) | Карточки игр | Полный набор → крафт значка (badge); фольга — редкая версия; значок можно прокачивать повторными наборами; XP и уровень профиля | Мета-коллекция поверх любимых игр, обмен с друзьями **[Steamworks, PC Gamer]** |
| **Neko Atsume** (2014–15) | Кошки | Ставишь угощения и игрушки, кошки приходят сами; фотоальбом с пустыми местами | Простота, «вычитание лишнего», выигрыш вне игры — когда делишься коллекцией в соцсетях; 10 млн загрузок к концу 2015 **[Wikipedia, everyeye]** |
| **Stardew Valley** (2016) | Предметы для общинного центра, музей | «Связки» (bundles): собрать набор предметов → комната восстановлена → награда (теплица, вагонетка) | Долгая цель, которая ведёт через все занятия игры; ощущение прогресса по комнатам **[TheGamer, Game Rant, Stardew Wiki]** |
| **Hollow Knight** (2017) | Записи о врагах | Дневник охотника: 168 записей, заполняется по ходу игры, за полный — награда и достижение | Коллекция = знание мира **[Hollow Knight Wiki]** |
| **Zelda: BotW** (2017) | 900 семян Короков | Короткие головоломки по всему миру; 450 семян уже дают все апгрейды, за 900 — шуточный предмет | Мини-сюрприз в каждом углу, **но** признан плохим примером: слишком много, награда пустая **[PC Gamer, GamesRadar]** |
| **Super Mario Odyssey** (2017) | Луны | Почти каждая луна — маленькая загадка; пороги 250 / 500 / 880 / 999 открывают новый контент | Поиск сам по себе — контент **[AV Club, substack]** |
| **Xbox Achievements** (с 2005, расцвет к 2013) | Достижения | Звук + всплывающее окно + очки Gamerscore, видимые друзьям; с 2016 — отдельный звук и «бриллиант» для редких | Очки «хранят воспоминания и историю» игрока **[AV Club, Digital Trends]** |

## 2. Общие механики

| Механика | Как работает | Где встречалась |
|---|---|---|
| **Редкость по цвету** | Серый/белый → зелёный → синий → фиолетовый → оранжевый/золотой. Корни — Diablo (1996) и World of Warcraft | Почти везде **[Game Informer, GiantBomb]** |
| **Ожидание до раскрытия** | Намёк на редкость (свечение, цвет луча) до того, как видно предмет | Hearthstone, Overwatch **[PC Gamer, Kotaku]** |
| **Таймер жалости / защита от дублей** | Гарантия, что редкое когда-нибудь выпадет; дубли превращаются в валюту | Hearthstone **[Hearthstone Wiki]** |
| **Слоты и таймеры** | Ограниченное число «открывашек», ожидание = причина вернуться | Clash Royale **[Game Developer]** |
| **Наборы и бонус за полный набор** | Собрал все карты набора → значок / награда | Steam, Stardew **[Steamworks, Stardew Wiki]** |
| **Альбом с пустыми местами** | Силуэт или «???» на месте ненайденного, счётчик «47 / 151», % по разделам, звезда за полный раздел | Покедекс, Neko Atsume, Starbound **[Starbounder, allthings.how]** |
| **Подсказки на закрытых ячейках** | Закрытая ячейка показывает редкость или намёк, где искать | inZOI, Starbound **[allthings.how]** |
| **Пороги с настоящими наградами** | Каждый порог открывает новый контент, а не косметику | Mario Odyssey **[AV Club]** |
| **Фольга / золотая версия** | Та же вещь, но «сияющая» — статус для коллекционера | Steam foil, Hearthstone golden, Pokémon holo **[Steamworks, cardcodex]** |
| **Ежедневный вход и события** | Награда за то, что открыл игру; ограниченные по времени предметы | Гача-игры **[Wikipedia: Gacha game]** |

## 3. Что делает коллекционный предмет хорошим

По докладу GDC 2025 «Making Collectibles Count» (бывший разработчик Diablo и Ghost of Tsushima) **[PC Gamer, GamesRadar]**:
- у предмета **понятная цель** — ясно, зачем его собирать;
- он **вписан в мир** и в основной процесс, а не разбросан ради количества;
- **не заставляет идти в интернет за гайдом** — поиск сам по себе интересный;
- **награда настоящая** — открывает новое, а не «пустышку».
