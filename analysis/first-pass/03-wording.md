# Надписи и микротексты

> Фразы, которые игроки узнают мгновенно. **[источник]** — проверено. **[≈]** — общеизвестные формулировки, без свежей проверки.

## 1. Узнаваемые формулы

| Фраза | Откуда | Что делает |
|---|---|---|
| **«Achievement Unlocked»** | Xbox 360 (с 2005) | Короткое признание заслуги + очки; к 2011 прозвучало 6,3 млрд раз **[AV Club, Game Informer]** |
| **«Gotta catch 'em all!»** | Pokémon | Цель коллекции в трёх словах **[≈]** |
| **«New!»** | Метка на новом предмете в коллекции | Тянет открыть и посмотреть **[≈]** |
| **«Legendary!»** / «Epic!» | Hearthstone, Overwatch | Название редкости = эмоция **[PC Gamer]** |
| **«You got…» / «You obtained…»** | Zelda, RPG | Момент получения предмета **[≈]** |
| **«Collection complete»** / золотая звезда | Starbound, альбомы | Финал раздела **[Starbounder]** |
| **«???»** | Альбомы, покедексы | Ненайденный предмет — интрига вместо пустоты **[allthings.how]** |
| **«Pity timer» / «Guaranteed»** | Hearthstone, гача | «Тебе точно повезёт» **[Hearthstone Wiki]** |
| **«Press Start»** | Аркады и консоли | Вход в игру **[≈]** |
| **«Game Saved»** / «Continue?» | Консоли | Безопасность прогресса **[≈]** |

## 2. Тон

- **Коротко, восклицательно, капслоком** для момента награды: VICTORY, LEGENDARY, LEVEL UP **[≈]**.
- **Спокойно и по делу** в меню: «Collection 47/151», «3 new» **[≈]**.
- **Слова-обещания** перед раскрытием: «New Pack Day», «Thrilling promise of the orange glow» — Blizzard продаёт ожидание, а не карту **[PC Gamer]**.

## 3. Что раздражает в текстах

- **Корпоративные оправдания вместо честности.** Ответ EA про Battlefront II — «ощущение гордости и достижения» за дорогую разблокировку — стал самым заминусованным комментарием в истории Reddit **[MCV UK, GameSpot]**.
- **Давление и срочность:** «Last chance», «Only today», таймеры распродаж — источник FOMO **[Game Developer]**.
